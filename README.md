# Асық — цифровая версия игры «Асық ату»

## О проекте

«Асық» — это простая 2D веб-версия традиционной казахской игры «Асық ату».

Игрок управляет сақой, выбирает направление и силу броска и пытается выбить асықов за пределы игрового поля.

Проект создан как современная цифровая адаптация традиционной игры для браузера.

## Для кого

Игра рассчитана на пользователей, которые хотят познакомиться с базовой механикой «Асық ату» в простом интерактивном формате.

## Как играть

1. Выберите направление броска.
2. Выберите силу броска.
3. Нажмите кнопку **«ЛАҚТЫРУ»**.
4. Сақа движется в выбранном направлении и взаимодействует с асықами.
5. Если асық вылетает за пределы круга, игрок получает **+10 очков**.
6. Если асық только немного сдвинулся и остался внутри поля, очки не начисляются.
7. За один раунд доступно **5 бросков**.
8. После пяти бросков раунд заканчивается.
9. Игрок может начать новую игру кнопкой **«ҚАЙТА ОЙНАУ»**.

## Правила и система очков

* За каждый асық, полностью вышедший за пределы игрового круга — **+10 очков**.
* За лёгкое касание без выхода асыка — **0 очков**.
* За промах — **0 очков**.
* Один асық не может принести очки повторно.
* После 5 бросков игра завершается.
* Лучший результат сохраняется в браузере.

## Авторские дополнения

В цифровой версии были добавлены:

* выбор направления броска;
* выбор силы броска;
* анимация движения сақи и асықов;
* физическое взаимодействие объектов;
* сохранение лучшего результата через `localStorage`;
* адаптивный интерфейс для компьютера и мобильного устройства.

Это упрощённая цифровая адаптация традиционной игры, поэтому физика движения не является полной симуляцией реального броска.

## Структура проекта

Основная логика игры находится в:

```text
src/
├── App.tsx
├── App.css
├── index.css
└── main.tsx
```

`App.tsx` содержит основную игровую механику, состояние игры, движение объектов, столкновения, подсчёт очков и управление раундом.

`App.css` и `index.css` отвечают за внешний вид и адаптивность интерфейса.

## Запуск проекта

Для запуска локально:

```bash
npm install
npm run dev
```

После запуска приложение будет доступно через локальный адрес, который покажет Vite.

## Использование AI

При разработке использовались AI-инструменты для:

* генерации и улучшения отдельных частей кода;
* поиска ошибок в игровой логике;
* обсуждения физики движения и столкновений;
* улучшения структуры интерфейса;
* проверки соответствия проекта требованиям задания.

Все основные части проекта были проверены и адаптированы под конкретную механику игры.

## Использованные компоненты

В проекте не использовались готовые игровые шаблоны или сторонний игровой движок.

Форма асыка реализована самостоятельно с использованием SVG.

Игровая логика движения и столкновений реализована внутри React/TypeScript.

## Ограничения

Проект является упрощённой 2D-адаптацией игры «Асық ату».

В нём пока отсутствуют:

* онлайн-мультиплеер;
* авторизация пользователей;
* серверная база данных;
* рейтинги и турниры;
* история игр между устройствами.

Для текущей версии основное внимание уделено рабочей игровой механике: прицеливанию, броску, столкновениям, выбиванию асыков, подсчёту очков и завершению раунда.
